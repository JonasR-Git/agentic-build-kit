# Provenance

This repository is a clean, source-only rewrite from Jonas Fendel's privately maintained personal tooling.

- No Git history was copied.
- No customer data, credentials, operational state, prompt libraries, provider integrations, or project-specific configuration was copied.
- The implementation is a smaller, provider-neutral core with new synthetic examples and focused tests.
